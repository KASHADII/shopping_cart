# Simple E-Commerce Cart 🛒

A minimalist, responsive shopping cart application built with pure HTML, CSS, and vanilla JavaScript. The UI design is highly inspired by the clean, modern aesthetics of [Cal.com](https://cal.com/), featuring high-contrast text, sleek borders, and an off-white background.

## Features ✨

- **Add to Cart**: Easily add products to the shopping cart.
- **Quantity Management**: Increment (`+`), decrement (`-`), or completely remove items directly from the cart.
- **Local Storage**: Your cart state is persistent! If you refresh the page or close the tab, your items will still be there.
- **Cal.com Inspired UI**: Clean and elegant interface using the Inter font for a premium look and feel.
- **Dynamic Total Calculation**: The total price is automatically updated as quantities change.
- **Interactive Checkout**: Provides visual feedback upon successful checkout before clearing the cart.

## Technologies Used 🛠️

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla, ES6+)

## Getting Started 🚀

1. Clone this repository:
   ```bash
   git clone https://github.com/KASHADII/shopping_cart.git
   ```
2. Navigate into the project directory:
   ```bash
   cd shopping_cart
   ```
3. Open `index.html` in your favorite web browser.
   - You can simply double-click the file, or use an extension like **Live Server** in VS Code for live reloading.

## Project Structure 📁

- `index.html`: The main HTML structure for the store and cart.
- `styles.css`: The styling file responsible for the Cal.com aesthetic.
- `script.js`: Contains all the logic for adding/removing items, updating quantities, and handling local storage.
